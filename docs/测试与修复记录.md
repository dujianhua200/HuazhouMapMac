## 二、测出并修掉的问题

| # | 现象 | 根因 | 修复 | 回归 |
|---|---|---|---|---|
| 1 | 侧栏底部「删除/清空」被窗口下沿裁切，状态栏压在上面 | `minHeight: 620` 超过小屏可用高度；VStack 中 `List` 抢占高度，把按钮区挤出边界 | minHeight 降到 480；tab 内容包 `Group` 加 `maxHeight: .infinity`；按钮区 `layoutPriority(1)`；按钮由 3 行压成 2 行 | 截图核验：底部控件完整可见 |
| 2 | 界面里填了中央子午线，保存后重开丢失 | UI 文本（`centralMeridianText`）与工程设置（`project.projection.centralMeridian`）是两份状态，只读不写回 | 改为计算属性，直接读写工程设置 | `centralMeridianPersists` |
| 3 | 清空工程后仍残留上次的中央子午线、对象类型 | `clearAll` 只重置了 project | 重置 `activeKind`；中央子午线随计算属性自动清空 | `clearAllResetsEverything` |
| 4 | 两个点同名时，CSV「距上点」列取到别人的段长 | 段长按**点名**建字典，重名互相覆盖 | 改为按链路序号映射 | `csvHandlesDuplicateNames` |
| 5 | 打字/拖动时界面卡顿（点数多时明显） | `chain` 是计算属性，每次访问都重算；300 点最近邻实测 **10.7 ms/次**，一次渲染访问 6~8 次 | 改成 `@Published` 缓存 + `project.didSet` 失效重算 | `chainCacheStaysInSync` |
| 6 | 双击地图缩放会打出两个点 | 每次 click 都直接落点 | 落点延迟 220 ms，双击时取消第一次 | 人工验证路径（见未覆盖项） |
| 7 | Finder 里双击 `.hzmap` / `open -a` 打不开工程 | 未实现文档打开事件 | 新增 `AppDelegate.application(_:open:)` + 终端 argv 两条入口 | 带数据启动截图核验 |
| 8 | 版本号仍写 1.0.0 | 打包脚本未更新 | 升 2.0.0 | 产物 Info.plist 核验 |
| 9 | 导出测试偶发失败 | 测试自身：连续导出 4 种格式后断言 message，被最后一次覆盖 | 在每次导出后立即断言 | 测试通过 |

## 三、环境坑（会反复咬人，已写进 README）

1. **只装 Command Line Tools 时 `@State` 不可用**：新 SDK 里 `@State` 是宏，缺 `SwiftUIMacros` 插件 → 本项目统一用 `@StateObject` + `@Published`。
2. **`swift test` 报 `TestingMacros ... plugin not found`**：增量构建的插件路径解析问题。**重跑不一定好使，`swift package clean` 一定好使**。
3. **SwiftPM 沙箱**被系统拒绝 → 加 `--disable-sandbox`。
4. **git 推送**：本机 HTTPS 走代理，`git push` 报 `CONNECT tunnel failed / Empty reply`，但 `gh api` 正常 → 用 Git Data API 落提交。

## 四、仍未覆盖（不装样子）

1. **UI 自动点击没做成**：`osascript` 控制 System Events 被系统拒绝（-10004），没有辅助功能权限。因此「地图单击打点」「拖动标注改位」「双击不误打点」「tab 切换」四项只有代码审阅 + 截图，没有自动化回归。
2. **分段页 / 设置页的视觉核验**只截图了默认的「点位」页；这两页用的是标准 `List`/`Form`，风险低但未亲眼确认。
3. **Apple 底图瓦片**依赖网络与地区，离线环境下无法验证；高德/腾讯预设需要外网 + 纠偏，未实测。
4. 真实 CAD/CASS 打开 DXF 的兼容性，仍靠导出后用解析器校验结构，没有在 AutoCAD 里真开过。
