## 3. 模块分解（从 RTTI 类名 + 资源 + 字符串还原）

原程序是**单体 exe 内分 8 层**，不是插件化架构。【推断，依据见各行证据】

### 3.1 界面层
- Ribbon + 可停靠窗格：`CBasePane/CAutoHideDockSite/CDockablePane/CDockSite/CDockingPanesRow`（5+ 类）
- 专用控件：`CAttaIconListCtrl`（附件图标列表）、`CChatRichEdit`（好友消息）、`CCityRichEdit`（天气城市）、`CImgComboBox`（图标选择）、`CTrackClassListCtrl`（轨迹分类）、`CDragTreeCtrl`（收藏夹拖拽树）、`CFriendPaneTree`（好友树）、`CCommonSuggestEdit`（搜索联想）
- 自绘菜单：`CChevronOwnerDrawMenu`、`CCommandManager`、`CContextMenuManager`

### 3.2 地图渲染层
- 瓦片金字塔 + OpenGL 纹理贴图；显示项：经纬度网格、路况、鹰眼、3D、反色/全白/灰底。

### 3.3 对象模型层
- 8 类对象：标签、轨迹、图形、线路、区域（弃用）、图片、附件、文件夹。
- 属性：`对象ID`、`对象类型`、`名称`、`关联属性`、`关联标签`、`标签属性扩展设置`、`备注模板`。
- 组织：收藏夹树 + 分组 + 排序（名称/类型）+ 显隐 + 上下移 + 分解/组合（`对象分解`、`轨迹组合`、`图形组合`）。

### 3.4 坐标引擎
- 三套并存：**经纬度**、**奥维平面坐标**（原点+比例尺+偏移的局部仿射）、**高斯-克吕格/横轴墨卡托**（PROJ `tmerc` + `towgs84` 七参数，覆盖北京54/西安80/CGCS2000）。
- 附加：`经纬度偏差修正`（GCJ-02）、`坐标批量转换`、`设置奥维坐标中心点`、`CAD 偏移`。
- 单位系统：面积（公制 sq.km/ha/are/sq.m、英制 sq.mi、市制 顷）、角度（圆周角/弧度/直角/百分度/度分秒/毫弧度）—— 从两个「单位设置」对话框还原。【实测】

### 3.5 数据 IO 层
- **自带完整 DXF 库**（22 个类）：`CDxfImport`、`CDxfImportHandle`、`CDxfHeader`、`CDxfLayer`、`CDxfBlock`、`CDxfInsert`、`CDxfInsertList`、`CDxfPoint`、`CDxfLine`、`CDxfCircle`、`CDxfArc`、`CDxfEllipse`、`CDxfPolyline`、`CDxfVertex`、`CDxfSpline`、`CDxfText`、`CDxfMultiText`、`CDxfImage`、`CDxfControlPoint`、`CDxfObjList`、`CDxfObject0/1`。
  → **DXF 是双向的**（导入+导出），且支持图像与样条；不支持 DWG。
- SHP 导入（shapelib）、KML、CSV、图片（TIFF/PNG/JPEG/位图）。

### 3.6 存储层
| 库 | 用途【推断】 |
|---|---|
| `omap.odb` | 瓦片缓存 + 离线地图（按级别/区域索引） |
| `oobj.odb` | 对象库（8 类对象 + 属性 + 附件索引） |
| `ocfg.odb` | 配置 + 授权状态 |
| `comp.odb` | 企业共享数据 |

### 3.7 设备层
- GPS 串口（`扫描GPS串口`）、蓝牙设备（`查找蓝牙设备`、`蓝牙设备管理`）、外置定位器 GT02a（IMEI/电话）、云端绑定设备、电子围栏/移动告警/报警统计。

### 3.8 服务层
- `CHttpGet` / `CHttpsGet` / `CHttpBaseStation`；`server.ovital.net`、`enserver.ovital.net`、`upgrade.ovital.com`。
- 云端同步（8 类对象增量比对）、好友/位置分享/跟随、企业服务器与共享空间、VIP 配额与授权、奥币/积分/签名社区。

## 6. 关键流程（推断 + 证据）

**离线下载**：区域多边形 → 逐级别计算瓦片行列范围 → 算下载量 → 多线程 HTTP 拉取 → 写 `omap.odb` 并登记区域/级别 → 浏览时优先读库。证据：`生成下载区域`、`计算下载量`、`地图数据库类型`、`绑定地图级别`、`老版地图数据转换成新版`。

**打点→出图**：屏幕像素 → 世界像素（Web Mercator）→ 经纬度 → 对象库（`oobj.odb`）→ 批量转平面坐标（PROJ）→ 生成 DXF 实体（`CDxf*`）→ 落盘。

**云端同步**：本地对象按 ID 与云端比对（`同步比对`）→ 列出将修改项 → 双向提交 → 回写状态。
