对照基准：`奥维地图-SVIP9.exe` 的 **8 个 MENU 资源 / 431 条菜单项 / 298 个不重复命令 ID / 302 个对话框 / 4897 个内部字符串键**（均由资源目录与字符串静态提取，见 `逆向分析报告.md`）。

## 二、为什么不追平

1. **瓦片授权**：原软件直连 Google/百度/搜狗等瓦片，这类"客户端聚合第三方瓦片"在国内属灰色，追平等于复制法律风险。本项目只给模板，由使用者自备源（自有服务/天地图 key）。
2. **服务端**：云同步、好友、企业空间、授权体系是一个后端产品 + 运营体系，不是客户端功能。
3. **终端生态**：GPS 采集/电子围栏/轨迹回放的核心价值在手机端（Android/iOS），macOS 桌面端做这个收益很低。
4. **工程量**：298 命令 + 302 对话框，是多年的商业软件规模。

## 三、路线图（按"对通信线路设计有多大用"排序）

### P0 — 让它真正替代手工（下一步就做）
1. **离线瓦片缓存**：自定义瓦片源按区域缓存到 SQLite，断网也能用（对应原"下载地图数据"）
2. **图片附件**：每根杆挂现场照片，随工程保存（对应"标签附件库"）
3. **DXF 导入底图**：把甲方图纸导进来当底图，在其上打点（对应"导入文件"）
4. **等间距插杆**：按档距在两点间自动插点（对应"等间距插入标签"）
5. **属性批量编辑**：按类型批量改杆高/材质/备注（对应"属性表"）

### P1 — 出图与协作
6. 打印/出图（1:500、1:1000，带图框与图例）
7. Shapefile 导出（测绘专业格式）
8. 多图层管理（线路/杆路/光缆分层导出）
9. 轨迹记录（配合外接 GPS 或手机导入 GPX）

### P2 — 生态
10. iCloud/文件同步（替代云端同步）
11. iOS 端（现场打点），与 Mac 端共用 `HuazhouCore`
12. 与通算宝预算打通（工程量→预算）
